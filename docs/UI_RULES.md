# UI RULES

## Design Principles

Simple.

Fast.

Clean.

Minimal.

---

## User Experience

Minimum clicks.

Immediate feedback.

Automatic saving whenever possible.

Real-time updates.

---

## Writing Experience

Letter should remain visible while browsing content.

Content lists should scroll independently.

Preview updates instantly.

---

## Design System

Keep consistent spacing.

Keep typography consistent.

Use existing colors unless feature requires customization.

Avoid unnecessary popups.
