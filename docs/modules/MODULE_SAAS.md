# MODULE - SUBSCRIPTIONS

## Purpose

Support free and paid plans.

---

## Scope

Free Trial

* One group.
* One letter.

Paid Plan

Unlimited access.

---

## User Flow

New user registers.

↓

Free trial starts automatically.

↓

User reaches plan limit.

↓

Upgrade screen appears.

↓

User purchases a subscription.

↓

Restrictions are removed.

---

## Functional Requirements

Track subscription status.

Track plan limits.

Prevent restricted actions.

Support plan upgrades.

---

## Business Rules

Existing data is never deleted.

Expired subscriptions only disable restricted features.

Users can renew at any time.

---

## UI Requirements

Usage indicator.

Upgrade button.

Plan information.

Remaining quota.

---

## Database Impact

Subscriptions.

Plans.

User subscription status.

Usage counters.
