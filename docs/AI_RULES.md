# AI RULES

## Purpose

AI should improve user productivity.

AI should never replace the user's personal writing.

---

## AI Usage

Allowed

* Spelling correction
* Grammar correction
* Punctuation
* Paragraph formatting
* Text formatting

Not Allowed

* Rewrite meaning
* Add content
* Remove content
* Change writing style
* Generate new personal messages

---

## AI Providers

The AI layer must remain provider-independent.

Implementation should allow replacing AI providers without changing application logic.

---

## Preferred Strategy

1. Prefer free or local models when quality is sufficient.

2. Use paid APIs only if they provide significant value.

3. Centralize all AI calls in a dedicated service.
